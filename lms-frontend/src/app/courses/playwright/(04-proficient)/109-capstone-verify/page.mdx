## The Verification Protocol

This is the final step of the entire course. You will run a structured verification protocol to confirm that every component of your framework is working correctly.

## Step 1: Environment Verification

```bash

node -e "
const required = ['BASE_URL', 'ADMIN_USER', 'ADMIN_PASS', 'REVIEWER_USER', 'REVIEWER_PASS'];
const missing = required.filter(k => !process.env[k]);
if (missing.length > 0) {
  console.error('Missing ENV vars:', missing);
  process.exit(1);
}
```

```bash
npx ts-node scripts/ast-audit.ts
# Expected: 5/5 gates passed
```

## Step 3: Full Test Suite Execution

```bash
# Run the complete suite with all browsers and generate HTML report
npx playwright test \
  --reporter=html \
  --reporter=list \
  --workers=4

# View results
npx playwright show-report
```

**Target metrics for certification:**
- ✅ 90%+ pass rate on first run
- ✅ No tests failing due to hardcoded waits
- ✅ Total execution time < 5 minutes
- ✅ HTML report generated successfully

Complete this checklist line by line:

```
CAPSTONE FINAL VERIFICATION CHECKLIST
```

## Claiming Your Certificate

Once all items are checked:

1. Submit a Pull Request to the `main` branch
2. All CI checks must be green ✅
3. A senior engineer reviews and approves the PR
4. Your E-Signature is applied to the Certification document in the DMS
5. You receive your digitally-signed **ASA Automation Engineer Certificate**

The certificate includes:
- Your name
- The certification level (Junior / Senior / Expert)
- The date of certification
- A cryptographic HMAC-SHA256 signature
- A QR code linking to the verification portal
