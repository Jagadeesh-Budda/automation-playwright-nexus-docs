## Test Quality Audit

Check each test against these quality criteria:

```typescript
import { test, expect } from '@playwright/test';

// For each test, verify:

// ✅ 1. Has a describe block
test.describe('Module Name', () => { ... });

// ✅ 2. Has a clear, readable name
test('admin can upload and submit a Protocol document', async () => { ... });

// ✅ 3. Follows AAA pattern
test('example', async ({ documentPage }) => {
  // Arrange
  const doc = DocumentFactory({ type: 'Protocol' });
  
  // Act
  const id = await documentPage.createDocument(doc);
  
  // Assert
  await expect(documentPage.getStatusBadge(id)).toContainText('Draft');
});

// ✅ 4. Cleans up after itself
test.afterEach(async ({ apiClient }) => {
  if (testDocId) await apiClient.delete(testDocId);
});

// ✅ 5. Does NOT depend on other tests' data
// Every test creates its own data
```

## Common Mistakes

> [!WARNING]
> **Mistake 1: Brittle Implementation**  
> **Wrong:** Tightly coupling test data with page interactions.  
> **Correct:** Abstracting data and logic appropriately.  
> **Why:** Prevents tests from breaking when minor details change.

> [!WARNING]
> **Mistake 2: Missing Synchronization**  
> **Wrong:** Relying on implicit speeds or hardcoded sleeps.  
> **Correct:** Using web-first assertions for synchronization.  
> **Why:** Guarantees deterministic execution regardless of environment speed.
